# Quick start

## Import bundle

Open PrusaSlicer and use:

```text
File > Import > Import Config Bundle
```

Import:

```text
dist/Soroush_Ender3V3SE_PrusaSlicer_2.9.6_config_bundle.ini
```

Restart PrusaSlicer if the presets do not appear immediately.

## Choose profiles

For a normal PLA model:

```text
Printer:  Creality Ender 3 V3 SE - Stock Marlin2 - 0.4 nozzle
Filament: Soroush PLA - 1.75mm
Print:    Soroush PLA - Quality
```

For Horn_L / mask / cosplay with the eSUN PLA+ spool:

```text
Printer:  Creality Ender 3 V3 SE - Stock Marlin2 - 0.4 nozzle
Filament: Soroush PLA+ - eSUN 1.75mm
Print:    Soroush PLA - Cosplay Mask Organic Supports
```

For quick tests:

```text
Print: Soroush PLA - Fast Draft
```

For strong brackets and mounts:

```text
Print: Soroush PLA - Mechanical Strong
Filament: Soroush PLA+ - 1.75mm
```
